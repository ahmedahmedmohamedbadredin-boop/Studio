## ✨ Website Features

- **5-Page Navigation:** Seamless, zero-reload single-page navigation across **Home**, **Services**, **Agent Suites (Products)**, **About Us**, and **Contact**.
- **Interactive AI Sandbox:** Live ReAct reasoning engine simulator demonstrating autonomous agent thought, tool execution, and outcome logging.
- **Service Inspection Modals:** Interactive pop-ups providing deep technical specifications, deliverables, and measurable ROI for every offering.
- **Theme Engine:** Integrated Dark / Light mode toggle with automatic OS color-scheme detection.
- **Lead Capture & Notification System:** Client-side AJAX form integrated directly with automated lead routing, sending structured lead tables instantly to inbox.
- **Responsive Architecture:** Fully optimized for mobile, tablet, and ultra-wide displays using Tailwind CSS.

## 🛠️ Technology Stack

- **Frontend:** HTML5, Tailwind CSS (via CDN), Vanilla JavaScript (ES6+).
- **Typography & Icons:** Inter (Google Fonts), FontAwesome 6 (Brands & Solid).
- **Backend (Optional / Local Dev):** Python 3.10+, Flask, Gunicorn.
- **Form Delivery:** FormSubmit AJAX REST integration with automated dispatch.
- **Hosting:** GitHub Pages (Static Edge CDN).
